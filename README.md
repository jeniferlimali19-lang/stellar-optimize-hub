# Control

Crie pra mim um prompt para o lovable de um painel que tenha tela de login, na tela de login quero uma logotipo e um campo pra digitar senha a senha será 123, no background eu quero que tenha um canvas estilo galáxia com pontos de interligando e formando pequenas conexões, não quero que eles fiquem aglomerados em um lugar só quero que eles se movimentem sempre, logo após a tela de login quero um card com funções 3 funções, as funções são: Reduzir Recuo, Retirar input lag e Otimizar Touch, coloque uma aba chamada funções onde terá as 3 funções e uma aba chamada informações. Abaixo das 3 funções mas ainda dentro do card quero um botão com um deeplink para abrir o Free Fire, lembrando mostre esse deeplink para o lovable, o deeplink não pode ter fall Back e nem começar com "https:" quero que ele abra o Free Fire diretamente.

O painel é na cor rosa. Crie uma svg demonstrativa e bem trabalhada pra cada função e para as abas

This project was built with [Lovable](https://lovable.dev).
